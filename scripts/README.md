# Scripts

Tekrarlanabilir komut sarmalayicilari burada tutulur. Scriptler veri setini
silmemeli veya orijinal etiketleri degistirmemelidir.

Senaryo algoritmalari `teshis/veri/senaryo_*.py` altindadir; E4 olcumu
`teshis/degerlendirme/senaryo_e4_cozunurluk_uyumsuzlugu.py` icindedir.
Buradaki senaryo betikleri parametre/ortam okur ve uygulamayi cagirir.
Her betigin basindaki aciklama asil uygulama dosyasini gosterir.
